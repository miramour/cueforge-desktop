# CueForge Desktop 0.2.0

- В настройках интерфейса можно задать число столбцов и строк от 1 до 12. При уменьшении сетки скрытые пэды сохраняются. Старые сеты открываются с прежней раскладкой.
- Кнопка «Начало отсюда» рядом с таймером запоминает позицию выбранного трека во время воспроизведения или на паузе. Следующий запуск пэда начинается с метки. Её можно поправить или сбросить в редакторе пэда.

Для Windows 10/11 x64 скачайте `CueForge-0.2.0-Windows-x64.exe`. Приложение запускается без установки. Если в банке используются ячейки после 32-й, сохраняйте сет в формате `.cueforge`. Формат обмена HCPL поддерживает первые 32 ячейки банка.
