# Исследование HypeCue и соответствие CueForge

Дата: 15 сентября 2026. Источники: [официальный сайт](https://hypecue.ru/), [история версий](https://hypecue.ru/changelog), официальный бесплатный дистрибутив 0.5.8. Проверены доступные вкладки интерфейса Free и экспорт пустого HCPL. Из файлов дистрибутива изучены перечень компонентов и поля сериализации плейлиста; код реализации в CueForge не переносился. Платная редакция не активировалась.

Главная страница указывает 0.5.8, история версий заканчивается на 0.5.6. Публичное описание не является полной спецификацией Pro. Скриншоты сайта изображают более раннюю версию.

## Существенные различия и проверки, которые ещё нужны

- Полная эквивалентность Pro не заявляется до сравнительных испытаний с активированной версией.
- Нет активации, ограничений Free/Pro и ограничения числа компьютеров.
- Уведомления об обновлении запрашиваются вручную через GitHub Releases.
- Библиотека копирует все новые файлы при включённом переключателе. Автоматическое определение съёмного носителя и запрос только для флешки пока отсутствуют.
- Устройство MIDI адресуется по порту Web MIDI. Группировка нескольких портов в одно физическое устройство не реализована.
- LED-профили используют стандартные Note/velocity-команды. Особые протоколы SysEx и все варианты Launchpad/APC требуют аппаратной проверки; поддержка каждой модели не обещается.
- HCPL переносит поля пэдов и метаданные банков. Непереносимые MIDI-идентификаторы чужого приложения не импортируются; контроллер назначается заново. Собственный `.cueforge` сохраняет полный набор настроек и назначений.
- BPM — оценка по ритмическим импульсам, возможна ошибка вдвое на сложной музыке. Значение можно исправить вручную.
- Короткие файлы воспроизводятся из ограниченного кэша Web Audio. Длинные — потоково через Chromium; точность границы обрезки/перехода зависит от планировщика и декодера. Sample-accurate gapless для длинных файлов не подтверждён.
- WAV ограничен 4 ГБ; при достижении границы запись завершается с сохранением заголовка. Авторазбиение на части пока отсутствует.
- Реальные MIDI, два физических выхода, длительный сценический прогон и поведение при горячем отключении оборудования требуют проверки на соответствующем оборудовании.

## HCPL

Документ JSON содержит `version`, `savedAt`, `pads`, необязательные `bankNames` и `bankColors`. В пэде используются `label`, `filePath`, `color`, `hotkey`, `volume`, `trimStart`, `trimEnd`, `loop`, `fade`, `fadeInSec`, `fadeOutSec`, `bank`, `slot`, `bpm`, `midiKey`. Пустой экспорт Free подтвердил оболочку версии 2; заполненные поля сверены со схемой сериализации. Выполнен собственный round-trip тест адаптера; обмен заполненным сетом с активированной Pro ещё не проверен.
