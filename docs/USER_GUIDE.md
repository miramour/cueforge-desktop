# Краткая инструкция

## Подготовка мероприятия

Назовите сет вверху окна. Добавьте файлы диалогом или перетаскиванием. Щелчок по пустой ячейке добавляет файл именно туда. Несколько файлов заполняют следующие свободные ячейки текущего банка. В одном банке помещается до 144 звуков.

ПКМ по вкладке банка позволяет задать имя и цвет. Пэды переставляются перетаскиванием; чтобы перенести между банками, задержите перетаскиваемый пэд над вкладкой нужного банка и отпустите над ячейкой. Кнопка содержимого открывает поиск по всему сету; двойной клик в списке запускает найденный звук.

## Пэды

ПКМ → настройки: название, цвет, громкость, повтор, фейд, времена появления и затухания. Пустая индивидуальная длительность использует общую настройку. Границы обрезки задаются выделением на волне или секундами; изменения применяются к следующему запуску. WAV-экспорт создаёт новый файл без изменения оригинала.

В разделе «Настройки → Интерфейс» укажите число столбцов и строк (по 1–12), затем нажмите «Применить сетку». Уменьшение сетки скрывает лишние пэды. Чтобы увидеть все ячейки, задайте 12×12. Сеты с заполненными ячейками после 32-й сохраняйте в формате `.cueforge`.

Во время воспроизведения или на паузе нажмите «Начало отсюда» рядом с таймером. При следующем запуске выбранный пэд начнёт звучать с этой точки. Чтобы вернуть вступление, в редакторе пэда задайте «Начало, сек» равным нулю.

## Воспроизведение

- Сингл: следующий пэд заменяет предыдущий; включённый у предыдущего пэда фейд плавно гасит его.
- Микс: несколько пэдов звучат одновременно.
- Плейлист: автоматический переход по ячейкам через все банки, пустые/потерянные пропускаются. В конце сета воспроизведение заканчивается.
- Пауза останавливает продвижение всех текущих голосов; Play продолжает их.
- Стоп останавливает весь звук сразу.
- Esc: первый раз — плавная аварийная остановка, второй во время затухания — немедленная. Диалог забирает Esc себе.

## Наушники и запись

В настройках аудио выберите зал и **другое физическое устройство** для CUE. Две записи одного устройства (например, Default и Communications) не считаются разными выходами. Кнопка наушников на пэде или Alt + клик включает прослушку. Кнопка CUE возле регулятора её останавливает.

Запись: выберите WAV, запускайте звуки, нажмите кнопку записи ещё раз. Пишется stereo PCM16 на частоте аудиоконтекста, после master и mute. Наушники в запись не попадают. Заголовок обновляется по мере записи; штатное завершение дополнительно сбрасывает данные на диск. Закрытие программы во время записи требует выбора в диалоге.

## Клавиатура и MIDI

Управление → нажмите поле назначения → нажмите клавишу. Backspace снимает привязку. Для клавиш вне окна выберите «Всегда»; занятые Windows или другой программой сочетания выводятся ошибкой в строке состояния. Латинские буквенные клавиши привязываются к физическому коду, поэтому сохраняются при русской раскладке.

MIDI → подключить → Управление → MIDI learn → нажать контроллер. Note Off/нулевая velocity не запускают пэд. CC master/cue меняют громкость непрерывно. В режиме ячеек кнопка меняет звук вместе с активным банком; в режиме пэда следует за конкретным звуком. Для LED выберите совместимый профиль и выход. На Launchpad может потребоваться пользовательский/Programmer mode.

## Перенос и восстановление

«Сохранить» записывает метаданные. «С файлами» дополнительно создаёт соседнюю папку аудио. В диалоге выберите `.cueforge` для полного сохранения настроек либо `.hcpl` для обмена треками. Переносите сет и его папку аудио вместе.

Если файл потерян: ПКМ по пэду → Указать файл. Программа обновит также найденные файлы из той же старой папки. Библиотека в настройках может автоматически копировать новые импорты в постоянное место.

Перед мероприятием проверьте сет, громкости, клавиши и оборудование в реальных условиях. Технические границы текущей версии перечислены в [FEATURES.md](FEATURES.md).
