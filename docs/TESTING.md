# Проверки Windows

Проверки выполнялись 15 сентября 2026 в Windows с настоящим Electron 44.3.0 и физическим системным аудиовыходом. Тестовые аудиофайлы синтезируются кодом; музыка третьих лиц не используется.

| Набор                   | Проверено                                                                                                                                                   |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm test`              | Валидация сетов, 256 ячеек, пропуск пустых/потерянных треков, HCPL round-trip, переносимые пути, PCM и WAV, 120 BPM, MIDI-сообщения, физические коды клавиш |
| `npm run test:e2e`      | Импорт, измеряемый звук, два голоса, пауза/продолжение, Esc, обрезка WAV, live-запись, клавиши, сет с файлами, сетка, темы, сохранение                      |
| `npm run test:formats`  | MP3, FLAC, OGG, AAC, M4A, Opus, WebM; потоковый 65-минутный FLAC; ограниченный анализ; экспорт на 60-й минуте; регистрация глобальной клавиши Windows       |
| `npm run test:controls` | Метаданные повторно используемого файла; переход буферного плейлиста; независимость CUE/записи; MIDI learn, дедупликация, LED, банки, CC                    |

В тесте перехода записывается реальный выход микшера, затем проверяется отсутствие провала длиннее 128 аудиокадров между короткими треками. Это проверка конкретного сценария, а не обещание нулевой задержки с любым устройством и любым файлом.

В тесте CUE **имитируется выбор второго устройства**, но используются настоящие независимые AudioContext и AudioWorklet. Подтверждается разделение аудиографов, а не работа физической USB-карты. MIDI-тест подставляет виртуальный MIDIAccess; его результаты не заменяют испытания железа.

Результаты и скриншоты сохраняются в `test-results/`, каждый запуск получает отдельный профиль. Эти профили, WAV и пути к локальным файлам не коммитятся. Тесты могут воспроизводить негромкий синтетический сигнал.

## Что нужно испытать дополнительно

Готовый `release/win-unpacked/CueForge.exe` также проверен скриптом `node scripts/package-smoke.mjs`: запуск со стандартным GPU-режимом, измеряемое воспроизведение, экспорт через встроенный FFmpeg, отсутствие ошибок renderer и корректное завершение WAV при закрытии окна во время записи. Эта проверка требует предварительной упаковки и `npm run demo`.

- Два физических аудиовыхода, отключение/подключение USB-карты в процессе.
- Конкретные MIDI-контроллеры и их LED-профили, hot-plug, несколько портов.
- Длительная запись мероприятия, заполнение диска, приближение к пределу WAV 4 ГБ.
- Чистые Windows 10/11, разные DPI, графические драйверы, устройства с повышенной задержкой.
- Обмен заполненными HCPL с активированной HypeCue Pro и сравнительные сценарии из её интерфейса.

CI собирает приложение и запускает модульные тесты на `windows-latest`. Сквозные аудиотесты выполняются локально: у hosted runner может не быть физического аудиоустройства.
